## 🎯 兩大題庫規格與特色

### 1. 🎖️ 成功嶺新訓題庫 (272 題)
- **是非題**：131 題（精選歷年 179T~257T 鑑測真題，含 247T、257T 打靶真題）。
- **選擇題**：141 題（四選一，提供標準答案與法規依據詳解）。
- **模擬考機制**：抽 50 題限時 40 分鐘，**60 分及格**，支援題目隨機打亂與選項洗牌。
- **題庫 PDF 下載**：收錄於 `pdf/替代役新訓題庫_全集彙編_標楷體版.pdf`（30 頁雙欄標楷體）。

### 2. 🚑 EMT-1 初級救護技術員題庫 (96 題)
- **100% 獨立分開**：與替代役法規題庫互不重疊，專注於 40 小時法定初級救護學科。
- **七大核心章節**：
  1. ⚖️ 緊急醫療救護法規與倫理 (12題)
  2. 🫀 基礎解剖與八大生命徵象 (14題)
  3. 🫁 呼吸道處置與氧氣治療 (15題)
  4. ⚡ 心肺復甦術與 AED (15題)
  5. 🩸 創傷評估止血固定搬運 (15題)
  6. 🏥 急症評估處置與休克 (15題)
  7. 🚨 大量傷病患 START 檢傷分類 (10題)
- **模擬考機制**：抽 50 題限時 50 分鐘，**70 分及格**，選項 (A)(B)(C)(D) 隨機打亂避免位置死記。
- **題庫 PDF 下載**：收錄於 `pdf/替代役EMT1初級救護技術員_全真題庫_標楷體版.pdf`（23 頁雙欄標楷體）。

## ⚖️ 最新法規嚴格對齊 (112~115 年最新公布)

本系統全面摒棄過時考古題之錯誤解答，所有法規題均直連全國法規資料庫官方最新條文：
1. **《替代役實施條例》**：
   - 110.01.27 最新修正：撫卹與保險給付請求權消滅時效延長為 **10 年**；國保保費由主管機關編列預算。
2. **《役男申請服替代役辦法》**：
   - 113.12.25 最新修正：家庭因素家屬年齡標準調高為 **65 歲以上**。
3. **《替代役役男請假規則》**：
   - 111.05.30 最新修正：「陪產檢及陪產假」合計 7 日（15日內請畢）；刪除事假 8 小時折算 1 日規定。
4. **《緊急醫療救護法》**：
   - 112.06.28 最新修正公布：增訂第 14-2 條救護免責（善良撒瑪利亞人條款）；第 23 條救護紀錄表法定保存 7 年；第 37、44 條洩漏病患秘密處罰鍰 2 萬至 10 萬元。
5. **《救護技術員管理辦法》**：
   - 112.05.08 衛福部令最新修正：初級 EMT-1 初訓 40 小時、證書效期 3 年、展延需 24 小時繼續教育（每年至少 8 小時）；明訂得施行之 12 項救護項目，嚴禁侵入性醫療。
