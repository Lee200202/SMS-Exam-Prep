## 🎯 七大核心功能與專屬模組

### 1. 🎯 隨機測驗 / 模擬考試 (Interactive Quiz Engine)
- **成功嶺期末標準模擬考**：標準 50 題（是非 25 題 + 選擇 25 題），限時 40 分鐘，考完即時評分、計算落點分析並生成各章節掌握度報告。
- **隨機快速刷題 (20題)**：零碎時間快速刷題，答題立即反饋標準答案與法條詳解。
- **專項章節測驗**：針對「替代役實施條例」、「志願服務法」、「役男權益」、「服勤獎懲」、「射擊國防」集中突破。
- **專屬錯題筆記本**：系統自動記錄做錯的題目於瀏覽器本機儲存（`localStorage`），支援一鍵重測所有錯題，直到完全掌握。
- **全題庫隨機洗牌**：支援 Fisher-Yates 演算法隨機打亂題目順序與選擇題選項順序。

### 2. 📖 全真題庫速查與背題模式 (Question Bank Viewer)
- 收錄 **262 題** 真題與重點試題（是非題 150 題、選擇題 112 題）。
- 即時關鍵字高亮搜尋（支援搜尋題目、選項及解析內文）。
- **背題遮罩模式 (Flashcard Mode)**：一鍵開啟答案模糊遮罩，點擊卡片才翻開答案，適合搭車、睡前刷題背誦。
- 標註歷年出題梯次標籤（如 `【205T考】`、`【247T考】`、`【257T考】`）。
- 支援題目收藏與一鍵複製題目及答案到剪貼簿。

### 3. ⚖️ 替代役實施條例與法規最新精要 (Regulations)
- **最新法規同步**：全盤校正至 110.01.27 修正條例、111.05.30 請假規則、112.09.20 內政部組改與 113.12.25 最新《役男申請服替代役辦法》。
- **役期與薪俸調整**：94年次以後役男役期回復為 1 年，薪俸調升為 NT$ 21,320 起；83~93年次維持 6 個月。
- **家庭因素審查新標**：113.12.25 最新修正，家屬年齡標準由 60 歲調高為 **65 歲以上**。
- **請假規則重大修正**：增列「陪產檢及陪產假」合計 7 日（15日內請畢）；刪除舊法事假「8小時折算1日」規定。
- **重要數字天數考點全覽**：驗退 30 天內、擅離職役逾 7 日移送、罰勤平日 2hr / 假日 8hr、罰薪 10%~30% 最多 3 個月、輔導教育最長 16 週、撫卹與一般保險給付請求權時效均延長為 **10 年**。

### 4. 🤝 志願服務法必考焦點 (Volunteer Service Act)
- 志願服務法定精神（自由意志、不以獲取報酬為目的）。
- 志願服務榮譽卡申請門檻：**滿 3 年、服務時數達 300 小時以上**，享公立文教風景區免費或優惠。
- 志願服務紀錄冊核發規則：**一人一本**，須完成基礎與特殊訓練。
- 志願服務運用單位之法定強制責任：**「應」為志工辦理意外事故保險**。
- 中央主管機關：**衛生福利部**。

### 5. 🎖️ 役男權益保障與新訓成績試算機 (Rights & Duty Management)
- 身分保障（不具現役軍人身分、保留學籍 1 年、保留底缺 3 個月、公費醫療與健保部分負擔全額補助）。
- 不當處分申訴管道（收到處分書次日起 30 日內向上級機關提出，受理機關 30 日內答覆）。
- **成功嶺軍事基礎訓練成績計算機 (247T最新更新標準)**：
  - 學科筆試 35%
  - 3000m 徒手跑步體能 15%
  - 徒手基本教練 20%
  - EMT-1 救護檢定 20%
  - 平時生活與內務考核 10%
  - 即時試算鑑測總分與分發競爭力評估！

### 6. 🎯 步槍打靶射擊訓練全攻略 (Shooting Training Guide)
- 靶場最高三大安全鐵則（槍口永遠朝前/朝上、手指未命不入扳機、故障立即舉手）。
- 射擊八大要領口訣：「**托、抵、握、貼、瞄、停、扣、報**」圖文並茂詳解。
- 步槍故障排除五大步驟：「**拍、拉、看、瞄、射**」。
- T65K2 突擊步槍諸元與 257T 鑑測常考重點（0-3 覘孔射擊 0~300m、避火罩主要功用為「減光」、箱上瞄準 5 分鐘畫 3 個三角形、槍械抵達由中隊長指揮驗槍）。
- 靶場標準射擊口令與動作流程。

### 7. 🎒 新訓必備用品建議檢核表 (Packing Checklist)
- 2024 年 8 月最新實測整理！
- 分類整理：
  1. 重要 A4 文件（L夾裝妥：徵集令、役期折抵成績單正本、最高學歷影本、郵局存摺影本等）。
  2. 重要證件與現金（身分證、健保卡、現金 2000~3000 元、夜光手錶、行動電源、有線耳機）。
  3. 個人生活與盥洗藥品（三合一好起泡沐浴乳、指甲剪附集屑盒、袖珍面紙、喉糖未開封、派卡瑞丁防蚊液、長尾夾內務神物）。
  4. 營站採買推薦物品（大塑膠袋x3、抽取式衛生紙、毛巾、藍白拖等）。
  5. 學長避坑提醒（奇異筆、針線盒、洗衣袋、防磨腳跟貼不用買；香菸打火機嚴禁攜帶）。
- 互動打勾即時同步瀏覽器儲存，提供一鍵列印 A4 清單功能！

### 8. 🚑 EMT-1 初級救護技術員專屬特區 (EMT-1 EMS Specialist Module)
- **與新訓法規題庫 100% 獨立分開、互不重疊**：依據法定 40 小時訓練教材與歷屆鑑測真題嚴格編修。
- **全真學科題庫 (96題)**：收錄 7 大單元（法規倫理、生命徵象、呼吸道氧療、CPR+AED、創傷止血固定、急症休克、START檢傷）全單選選擇題。
- **選項與題目隨機洗牌**：支援 Fisher-Yates 演算法隨機分配題目順序，並隨機打亂 (A)(B)(C)(D) 選項分配，避免死背選項順序。
- **多元測驗模式**：
  - **50題期末全真模擬考**：完全比照成功嶺期末 70 分及格標準與 50 分鐘限時。
  - **20題高頻速測練習**：即做即批，即時呈現粗體答案、醫學法規詳解與官方出處。
  - **專屬 EMT 錯題筆記本**：自動追蹤答錯題目，支援單獨重測。
  - **章節專精測驗**：針對弱點救護單元集中突破。
- **核心急救法規與重點筆記**：
  - 救護技術員管理辦法與 12 項法定得施行救護項目（嚴禁侵入性給藥與插管）。
  - 八大生命徵象正常值與危急標準表。
  - 格拉斯哥昏迷指數 (GCS) 完整評分與臨床分級。
  - 成人生存之鏈與高品質 CPR+AED 五大黃金指標。
  - 氧氣治療設備濃度流量表與高壓氧氣鋼瓶可用時間計算公式。
  - 創傷 XABCDE 與重大處置要領（止血帶CAT、頸圈長背板、斷肢隔水冷藏）。
  - 大量傷病患 START 檢傷分類決策流程圖 (RPM 法)。
- **十大學習資源清單**：收錄消防署官方教材電子書、全國法規資料庫、Dcard 265T/264T/270T 快速參考手冊、阿摩線上測驗、Quizlet 與急診醫學會指引，提供官方直連。
- **專業標楷體 PDF 題庫**：產出 `pdf/替代役EMT1初級救護技術員_全真題庫_標楷體版.pdf`，標準 A4 表格排版，粗體高亮答案並附帶可點擊法規超連結。

## 🛠️ 技術架構
- **純前端零依賴架構**：原生 HTML5 + Tailwind CSS + Vanilla Modern JavaScript (ES6+)。
- **離線與靜態託管支援**：內建 `data_bundle.js`，雙擊 `index.html` 或託管於 GitHub Pages 均零 CORS 錯誤。
- **響應式設計 (RWD)**：支援 iPhone、Android、iPad、Mac 與 Windows 完美適配。
- **深淺色模式**：自動偵測系統外觀並可手動一鍵切換。
