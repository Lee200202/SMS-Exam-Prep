# 成功嶺替代役新訓備考（SMS Exam Prep）

替代役基礎訓練學科與 EMT-1 的題庫練習網站，附法規全文與入營用品清單。

- 線上版：<https://lee200202.github.io/SMS-Exam-Prep/>
- 這是役男自行整理的非官方資料。題目來自歷屆役男分享，內容如與主管機關公告不同，以公告為準。

審核者是 AI，目前沒有人工複核。「有沒有考過」和「答案對不對」分開標示，每一題在題庫頁都看得到。

- EMT-1 直接匯入 61 題：274T 考古題整理檔的 11 個新考點（選項為站方補寫）與〈2022 EMT-1 筆試考古題〉文件的 50 題（照文件轉錄），是依站主提供的資料直接匯入的，**沒有核實**；2022 年那份文件沒有標示考試單位或梯次。詳見 [docs/1004匯入紀錄_2026-10-04.md](docs/1004匯入紀錄_2026-10-04.md)。
- EMT-1 回憶考點 46 題：Dcard 270T 文章的 Part 1 是梯次不明的舊考點，Part 2 六題是作者記下的當梯新題；本站題幹與多數選項為重寫，並非逐字原題。96 題 AI 自編概念練習另存一份，沒有考過的證據，尚未逐題對照 114 年教材；正解常是最長或唯一含英文的選項。

**答案對不對（查核狀態）**——詳見 [docs/逐題審核_2026-10-04.csv](docs/逐題審核_2026-10-04.csv)、[docs/資料查核紀錄.md](docs/資料查核紀錄.md)

- 新訓：182 題已和現行條文逐字比對；其餘為條文只支持一部分、查無條文、射擊經驗題或舊法題，題目上都有標示。
- EMT-1 回憶考點 46 題：7 題對照現行法規條文，35 題對照消防署 114 年版教材（題目上附電子書頁碼），2 題在教材文字層找不到，1 題教材條件與回憶題幹不符，1 題回憶者註明過時。逐題結果見 [docs/114年EMT逐題教材核對.csv](docs/114年EMT逐題教材核對.csv)。審閱者是 AI，沒有具救護資格的人複核，不適合作為現場急救的依據。96 題自編概念練習沒有對照 114 年版教材。

**模擬考只出有來源的題目**

## 作答規則

- 未作答的題目不計分，也**不會**加入錯題本。結果頁分開顯示答對、答錯、未作答。
- 模擬考交卷後才判定對錯，錯題以交卷時的最終答案為準。練習模式每題作答後立即鎖定並顯示解析。
- 選項會隨機排列，正解跟著選項走；含「以上皆是」這類選項的題目不打亂。
- 模擬考只從有來源的題目出題（見上）。
- 兩個分頁同時開同一份測驗時，後接手的分頁生效，另一個分頁會暫停並提示，不會互相覆寫。
- 模擬考以實際時間計時。離開測驗頁或重新整理會自動暫停，回到測驗頁可繼續；時間到自動交卷。
- 錯題本、收藏、未完成的測驗與清單勾選只存在瀏覽器的 localStorage，首頁可以匯出、匯入或一鍵清除。

## 專案結構

```
index.html            頁面骨架
css/style.css         樣式（手寫，無 CSS 框架）
js/app.js             主程式（無外部相依）
data/*.json           題庫、講義、法規資料（原始資料）
data/data_bundle.js   由 JSON 產生的資料包（首頁載入）
data/laws_index.js    法規清單（進入法規頁才載入）
data/laws/<代碼>.js   單一法規的全文與附件文字（展開或搜尋時才載入）
docs/                 逐題審核表、查核紀錄、法規比對、效能量測、上線報告
pdf/                  新訓、EMT 回憶考點、EMT 自編練習及用品清單 PDF
scripts/              資料下載、檢查、打包、PDF 產生與瀏覽器測試
```

網站是純靜態檔案，沒有後端也沒有外部 CDN，可直接部署在 GitHub Pages，或雙擊 `index.html` 開啟。

## 修改資料後要做的事

```bash
python scripts/fetch_laws.py --check   # 重新下載 20 部法規並逐條比對，列出差異與受影響題號（有差異時結束碼非 0）
python scripts/fetch_laws.py           # 確認要更新後，覆寫 data/laws.json
python scripts/build_all.py            # 套用逐題查核 → 逐題溯源 → 資料包 → 分冊 PDF → manifest → 資料檢查
python scripts/test_app.py             # 瀏覽器回歸測試（需要 playwright）
python scripts/measure_perf.py <網址>   # 效能與對比量測，寫入 docs/
```

`scripts/test_app.py` 後面加網址可以直接測線上版，例如
`python scripts/test_app.py https://lee200202.github.io/SMS-Exam-Prep/`。

發版前的阻擋條件都在 `scripts/validate_data.py`：題庫結構、來源連結對應的法規已收錄、附件逐件取得、逐題審核表涵蓋每一題且答案一致、模擬考題池足夠且不含舊法題、資料包與 PDF 是用目前的 JSON 產生。

回滾：`git revert <提交>` 後推送即可，GitHub Pages 會重新部署；使用者的錯題與收藏存在瀏覽器，不受影響。

`scripts/` 內其餘 `update_*`、`merge_*`、`build_*` 等是早期整理資料用的一次性腳本，重跑會覆蓋目前已校對的 JSON，請不要再執行。
