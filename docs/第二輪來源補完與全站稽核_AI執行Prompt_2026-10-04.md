## 429 題及全站的具體查核流程

1. **固定基線**：記 Git HEAD、工作樹狀態、線上主要檔案 SHA-256、`README` 題數與 `data/questions.json`、`data/emt_questions.json`、`data/emt_practice_questions.json` 的實際題數。目前是新訓 287（其中自編 50）＋EMT 回憶 46＋EMT 自編 96＝429；修改後動態重算。現有 `docs/question_provenance.csv` 是 AI 判斷，需抽回來源全文、逐列複查，不能因有 CSV 就視為人工核實。
2. **來源登錄**：重做 `docs/sources.csv`，每筆包含最終 URL、內容標題、作者、日期、可讀頁數、擷取方法、頁面／題號、原題選項與答案有無、來源血緣、許可及限制。至少開十個直接內容來源；非成功嶺來源必須排除於「成功嶺原題」計數外。特別把 260T、265T、第三篇未核實連結與 PTT 上游補完。
3. **逐題雙軸裁定**：一軸是出題史（原卷／當梯作者回憶／講師轉述／民間彙編／教材概念／站方自編／未知），另一軸是現行正確性（現行法條或 114 教材支持／部分支持／衝突／需專業複核）。即使來源有梯次標記，也須分別記「作者聲稱」與「外部佐證」。每一題保留原文、站文、差異、答案、頁碼及決策；只正規化空白與標點才能標「逐字相同」。回憶題欠缺四選項時，網站補造選項必標「站方補寫」。
4. **114 教材逐題審**：對至少全部 EMT 現行公開題和獨立練習區的 96 題逐題找教材章／頁；優先查 CPR 有無脈搏、兒童／嬰兒／新生兒分類、GCS、氧氣、抽吸、檢傷、中風、創傷、血糖、EMT-1／EMT-2 權限。遇到新版與 108 年教材或 260T 舊筆記不一致，記兩版答案及生效時間。不得自行提供現場醫療操作結論；由具資格的 EMT 教官、醫師或相關專業審閱高風險爭議題。
5. **模擬考與章節練習**：公開站和本機各完成新訓 50 題及 EMT 40 題測驗，測暫停、重整、離頁、逾時、改答案、錯題本、收藏與舊資料遷移。多個亂數種子抽卷，確認來源等級、題目重複、選項洗牌後答案文本與得分。含「以上皆是」或順序依賴題不得錯洗牌。確認 96 題不進來源題隨機練習，僅進自編題隨機入口；章節練習明確勾選後才納入，始終不入模擬考；題池不足就顯示實際題數，不自行湊題。
6. **全站內容與 UI**：跑所有 hash 路由及內文搜尋；查法規 21 部全文與 65 附件、PDF、用品清單、重點整理、資格與分數說明、出題狀態標籤、手機 360／390／430、平板 768、桌機 1280、深淺色、鍵盤與讀屏。所有自動測試均通過不代表螢幕閱讀器或醫學內容已核實；把未測與待複核分開列。版面可局部或全面重做，但維持清楚的來源／現行狀態標籤、舒適的題幹與選項行距、少量穩定的顏色及可回到原題的連結。
7. **資料流與速度**：網站是 GitHub Pages 靜態站，需量 `data_bundle.js` 首載、法規分檔載入、搜尋回應、手機 4G、快取與重試；不要泛稱 API。檢查建置順序與舊一次性腳本是否會覆蓋人工審核。新增 CI 或發版門檻：來源表和題庫 ID 完整、自編題在題庫頁、隨機入口及 PDF 均清楚分區，模擬考題池符合來源政策、法規版本與附件完整、部署 hash 一致。
